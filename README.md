# Stakeholder Analysis — Анализ заинтересованных сторон

## О проекте
Учебный проект Школы 21 (индивидуально).  
Провёл комплексный анализ стейкхолдеров для выявления потребностей, влияния и стратегий взаимодействия с заинтересованными сторонами проекта.

## Моя роль
- Идентифицировал всех ключевых стейкхолдеров проекта
- Проанализировал их интересы, влияние и уровень вовлечённости
- Разработал матрицу власти/интереса (Power/Interest Grid)
- Сформировал стратегии коммуникации для каждой группы

## Выполненные задачи

### Задание 1: Идентификация стейкхолдеров
- Составил полный список заинтересованных сторон
- Классифицировал их по ролям (внутренние/внешние)
- Определил их интересы и ожидания от проекта

### Задание 2: Анализ влияния и интересов
- Оценил уровень власти каждого стейкхолдера
- Определил степень заинтересованности в проекте
- Построил матрицу Power/Interest Grid

### Задание 3: Стратегии взаимодействия
- Разработал подходы к работе с каждой группой:
  - Manage Closely (высокая власть, высокий интерес)
  - Keep Satisfied (высокая власть, низкий интерес)
  - Keep Informed (низкая власть, высокий интерес)
  - Monitor (низкая власть, низкий интерес)

### Задание 4: План коммуникации
- Определил частоту и формат коммуникации для каждой группы
- Выявил потенциальные конфликты интересов
- Разработал стратегии управления ожиданиями

## Результаты
- ✅ Полный реестр стейкхолдеров с детальным описанием
- ✅ Матрица Power/Interest Grid для визуализации влияния
- ✅ Стратегии взаимодействия для каждой группы
- ✅ План коммуникации с учётом потребностей стейкхолдеров

## Инструменты
- Stakeholder Mapping
- Power/Interest Grid
- RACI матрица
- Методы качественной и количественной оценки

## Структура проекта
- `src/stakeholder-register/` — реестр стейкхолдеров
- `src/power-interest-grid/` — матрица анализа
- `src/communication-plan/` — план коммуникации
